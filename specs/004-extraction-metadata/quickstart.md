# Quickstart: Extraction Metadata

## Validation Scenario 1: Preview Window
1. Open the application.
2. Load a PDF and Template.
3. Click **Preview Extraction**.
4. **Verify**: The spreadsheet view now contains columns for `file name`, `file path`, `generated time`, `user`, and `template name` populated with real data.

## Validation Scenario 2: Batch Export
1. Open the application.
2. Click **Run Batch Extraction**.
3. Select an input directory and specify an output CSV file.
4. Run the batch.
5. **Verify**: Open the output CSV file and ensure the first columns contain the standard metadata (`file name`, `file path`, `generated time`, `user`, `template name`).
